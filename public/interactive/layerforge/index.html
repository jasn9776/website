        Training is not available in the online version.
        
This tab trains the model you designed on MNIST digits, Fashion-MNIST, CIFAR-10 or your own image folders, and logs each run. It needs Layerforge's local server (Python and PyTorch on your own computer), so it is switched off in this online version.

        
Everything else runs right here in your browser: build a model from the palette or a preset, copy its PyTorch or Keras code, and explore it in the diagram and 3D tabs, where any convolution or pooling layer can be animated. You can also browse the author's experiment log: models built here, trained, and compared.

      

      

        Training runs on your own machine through a small local server, and it is not running.
        
In a terminal, from this project folder, using the Python that has torch installed:

        
python serve.py

        
It opens the builder at http://localhost:8765. This tab then trains the model directly and keeps checking for the server in the meantime.

        
This page was opened as a file. For safety the server only talks to the copy it serves itself, so open http://localhost:8765 once it is running.
